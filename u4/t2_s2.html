Diseño Responsive y CSS

Diseño Web Responsivo (RWD)

Es un enfoque donde los diseños web se ajustan automáticamente al tamaño y formato de la pantalla donde se visualiza el contenido (Pág. 167).

Estrategia RWD

El servidor envía el mismo código HTML a todos los dispositivos y se utiliza CSS para modificar la representación visual en cada uno (Pág. 168).

Mobile First Web

Implica comenzar el diseño desde la resolución más pequeña y luego expandir y ajustar el contenido a pantallas mayores (Pág. 168).

Frameworks CSS Recomendados

Para evitar escribir todo el código desde cero y garantizar compatibilidad entre navegadores, el compendio destaca los siguientes frameworks (Págs. 169-171):

Bootstrap

El más utilizado y solicitado. Incluye reglas para casi todos los estilos web.

Foundation

Evolución constante desde 2011. Permite trabajar con apps y correos electrónicos.

Pure CSS

PESO: < 4 KB

Ideal para proyectos rápidos que requieren una carga extremadamente ligera.

Milligram

PESO: 2 KB

Minimalista y plano. Solo compatible con navegadores modernos (Pág. 171).

Análisis de Frameworks (Pág. 169)

Ventajas
  • Ahorro de tiempo (base lista).
  • Compatibilidad con navegadores garantizada.
  • Escalabilidad para el futuro.
Desventajas
  • Puede limitar la creatividad (diseño prefijado).
  • Líneas de código innecesarias (archivos pesados).
  • Tiempo de aprendizaje inicial.
