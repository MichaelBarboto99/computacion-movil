Escenarios de ejemplo con Servicios

PASO 1: SERVIDOR

Generación del CRUD en Node.js

Se utiliza el framework Express para crear los endpoints relacionados a un CRUD (Pág. 148). Como base de datos, se emplea un archivo .json para la persistencia de datos de estudiantes.

  • Endpoint de lista: Devuelve todos los registros.
  • Endpoint por ID: Obtiene un estudiante específico.
  • Escenario: El servidor responde en el puerto 3000 o 8888 según la configuración.
PASO 2: CLIENTE

Consumo con Retrofit (Android)

Para obtener la información del servidor en Android Studio, empleamos la librería Retrofit (Pág. 151). Este es el proceso técnico estándar:

1
Configuración Gradle: Agregar las dependencias de Retrofit y el conversor GSON en libs.versions.toml (Pág. 151).
2
Permisos: Declarar el permiso de INTERNET en el archivo AndroidManifest.xml (Pág. 151).
3
Modelado y API: Crear la clase Estudiante (POJO) y una Interface que defina las peticiones @GET (Págs. 152).
4
UI y Adaptador: Implementar un ListView en el XML y un ArrayAdapter en Java para visualizar los datos (Pág. 153).
