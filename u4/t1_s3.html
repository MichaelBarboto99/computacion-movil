Desarrollo de Servicios en Nodejs

Node.js es un entorno de ejecución de código abierto y multiplataforma que permite ejecutar JavaScript fuera del navegador. Es ideal para construir aplicaciones de red rápidas y escalables (Pág. 142).

El Motor y la Arquitectura

Utiliza el motor Chrome V8 que convierte el código JavaScript a código máquina en tiempo real (JIT). Su principal característica es el uso de un "Single Threaded Event Loop".

  • No bloqueante: Gestiona múltiples conexiones simultáneamente sin abrir múltiples procesos.
  • Eficiencia: Ejecución de hilos asíncronos que garantiza respuestas veloces en el procesamiento de datos.

Guía Práctica: Crear un Servicio Web (Págs. 145-147)

Para desarrollar servicios web robustos, el compendio recomienda el framework Express.

1. Instalación de Herramientas

Debes ejecutar los siguientes comandos en el directorio de tu proyecto:

$ npm install express
$ npm install request

2. Lógica del Servidor (application.js)

En este archivo definimos los controladores y las rutas. Un ejemplo básico para consumir datos de una API externa (como JSONPlaceholder):

const express = require("express");
const app = express();

app.get('/users', (req, res) => {
  // Lógica para obtener datos JSON...
  res.send(data);
});

app.listen(8888, () => console.log('Servidor corriendo...'));

3. Ejecución y Prueba

Para poner en marcha el servicio, utiliza el comando:

$ node application.js

Luego, abre tu navegador e ingresa a: http://localhost:8888/users/
