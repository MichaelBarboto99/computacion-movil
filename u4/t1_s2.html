Elementos de un Microservicio

Un microservicio es una unidad autónoma compuesta por varios componentes técnicos que trabajan en conjunto para proporcionar una funcionalidad específica. Según la página 140 del compendio, estos son sus elementos esenciales:

Lógica de Negocio

Es la parte central. Contiene el código que realiza las operaciones y procesos necesarios para cumplir el propósito del servicio.

API (Interfaz)

Define cómo otros servicios interactúan con él. Proporciona una forma estandarizada de enviar solicitudes y recibir respuestas.

Persistencia de Datos

Maneja el almacenamiento. El microservicio puede tener su propia base de datos o acceder a una compartida según los requisitos.

Configuración

Controla el comportamiento del servicio, incluyendo conexiones a bases de datos y parámetros de seguridad.

Gestión de Errores

Mecanismos para manejar fallos y registrar información (logs) relevante para el seguimiento y diagnóstico técnico.

Capa de Transporte

Define los protocolos de red para la comunicación, siendo los más comunes HTTP y TCP.

Contenedor y Entorno de Ejecución

Finalmente, el microservicio se ejecuta en un entorno como Docker o una máquina virtual. Este componente proporciona los recursos necesarios de memoria, CPU y aislamiento para su funcionamiento óptimo.
