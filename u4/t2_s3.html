Construcción de Aplicaciones Móviles Híbridas

La construcción híbrida permite desarrollar una sola aplicación que funcione en múltiples plataformas (móviles, tablets y ordenadores) con un rendimiento consistente y un costo menor (Pág. 172).

Ionic Framework

Es una herramienta poderosa de código abierto que utiliza lenguajes familiares (HTML5, CSS y JavaScript/TypeScript) para ofrecer una experiencia de desarrollo sencilla y flexible.

Ventajas
  • Multiplataforma (Android, iOS, Web, FireOS).
  • Gran biblioteca de componentes (UI-Kit).
  • Bajo costo y ahorro de recursos.
Limitaciones
  • No apto para alta carga gráfica (juegos).
  • Posibles errores de compilación por versiones de SO.

Otras Alternativas de Construcción (Pág. 174-175)

React Native

JavaScript / React

Crea aplicaciones nativas reales. Los componentes no se ejecutan en un navegador, sino directamente en el hardware móvil.

"Hot Reloading" instantáneo.
Rendimiento casi nativo.

Flutter

Dart / Skia

Utiliza el lenguaje Dart y el motor Skia para renderizar su propia interfaz. Garantiza una UI uniforme en todas las plataformas.

Altamente personalizable.
Compilación a código máquina.

Dato Técnico (Pág. 172): Los componentes de Ionic están compuestos por elementos personalizados que ofrecen métodos, eventos y propiedades CSS, lo que simplifica la creación de interfaces modernas.
