Plataformas de desarrollo móvil

Clasificación según su naturaleza

Nativas

Diseñadas específicamente para cada SO:

  • iOS: Objective-C
  • Android: Java
  • Windows Phone: .NET

Ventaja: Aprovechan al máximo el hardware y funcionan offline.

Híbridas

Fusionan características nativas y web.

  • Usan JavaScript, CSS y HTML.
  • Se adaptan a cualquier SO.
  • Acceso total a funcionalidades del dispositivo.

Multiplataforma

La opción más solicitada para reducir gastos.

  • Acelera el proceso de desarrollo.
  • Ajuste perfecto a diversas plataformas.
  • Desventaja: No siempre aprovechan el 100% de las funciones del terminal.

Herramientas y Frameworks

Web / HTML5 JS / CSS / HTML

Eliminan la necesidad de un desarrollo específico por cada SO. Se ejecutan directamente desde el navegador móvil integrado.

React Native JavaScript

Permite un rendimiento casi nativo aprovechando un lenguaje ampliamente conocido. Es de las opciones más populares actualmente.

Flutter Dart

Creada por Google. Destaca por su sistema de widgets que permite una personalización amplia y sencilla de las interfaces.

Xamarin C#

Propiedad de Microsoft. Ideal para compartir código entre plataformas y ahorrar tiempo de desarrollo usando .NET.

Ionic Tecnologías Web

Simplifica la transición de desarrolladores web al móvil. Ofrece un rendimiento robusto y admite plugins nativos.

PhoneGap (Apache Cordova) HTML / CSS / JS

Atractivo por su facilidad de uso. Aunque su rendimiento no iguala a las nativas, permite crear apps web muy atractivas.
