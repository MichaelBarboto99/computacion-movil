TEMA 1 - SUBTEMA 3

Herramientas para el desarrollo multiplataforma

El mercado ofrece una amplia gama de frameworks que permiten ampliar el alcance de las aplicaciones a una audiencia masiva con un solo desarrollo.

React Native

LENGUAJE: JavaScript

Creado por Facebook. Es la elección preferida para apps dinámicas como Uber.

  • Utiliza elementos nativos.
  • Recarga en caliente (Hot Reload).
  • Integración perfecta con terceros.

Flutter

LENGUAJE: Dart

Desarrollado por Google. Crea interfaces altamente eficientes y receptivas.

  • Widgets personalizables expresivos.
  • Detección de errores integrada.
  • Compatible con Swift y Java.

Xamarin

LENGUAJE: C# / .NET

Propiedad de Microsoft. Ideal para compartir código entre iOS, Android y Windows.

  • Acceso completo a la API nativa.
  • Uso del framework Mono.
  • Bibliotecas de alto rendimiento.

Ionic

LENGUAJE: HTML5 / CSS / JS

Ideal para aplicaciones híbridas. Muy fácil de usar para desarrolladores web.

  • Base de código unificada.
  • Emulación de interfaz nativa.
  • Gran biblioteca de componentes.

Otras Soluciones

El compendio también destaca herramientas especializadas:

  • Unity: Potente motor para juegos 3D.
  • Appery.io: Plataforma de bajo código (Drag & Drop).
  • Sencha: Enfoque en componentes web probados.
  • Alpha Anywhere: Orientado a nivel empresarial.

Firebase (Backend-as-a-Service)

La oferta principal de Google para proporcionar servicios de base de datos, hosting y métricas sin necesidad de programar en el servidor. Es el complemento ideal para estas herramientas.
