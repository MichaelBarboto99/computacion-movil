Wireframes y Prototipado

¿Qué es un prototipo? Es una representación preliminar de una aplicación. Funciona como un esquema inicial que permite realizar pruebas, recibir comentarios e implementar mejoras antes de dedicar tiempo a la codificación completa.

Evolución del Diseño

El diseño de una aplicación no ocurre de un solo paso; evoluciona a través de diferentes niveles de detalle:

Fidelidad Baja

1. Sketch (Boceto)

Es el primer esbozo realizado a mano en papel o tablero. Captura ideas generales sin requerir un trabajo conceptual exhaustivo.

  • Define qué contenido y servicios incluir.
  • Plantea la estructura de navegación básica.
  • Fomenta la creatividad y visión inicial.
Fidelidad Baja/Media

2. Wireframe

Representación básica en tonos de gris. Es el "primer paso significativo" del diseño digital.

  • Detalla áreas de contenido y estructura HTML.
  • No incluye colores, tipografías ni imágenes.
  • Establece el flujo de navegación (conexión de pantallas).
Fidelidad Media

3. Mockup

Fase avanzada del diseño gráfico. Aquí se define la identidad visual de la aplicación.

  • Define la paleta de colores institucional.
  • Establece dimensiones, iconografía y estilos CSS.
  • Muestra textos simulados para ver el impacto visual.
Fidelidad Alta

4. Prototipo

Versión casi final que simula la interacción real. Es el paso previo al desarrollo final.

  • Permite operar sistemas de navegación y búsqueda.
  • Se utiliza para pruebas con usuarios beta.
  • Identifica dificultades antes de programar el código definitivo.
