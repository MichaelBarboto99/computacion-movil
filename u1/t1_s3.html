Tipos de apps

Existen tres categorías principales de aplicaciones móviles, cada una definida por su lenguaje de programación y la forma en que se ejecutan en el dispositivo.

1. Aplicaciones Nativas

Se desarrollan específicamente para un único sistema operativo (Android o iOS) utilizando el lenguaje propio de cada plataforma (Kotlin/Java para Android, Swift para iOS).

Ventajas
  • Mejor rendimiento y velocidad.
  • Acceso total al hardware (GPS, cámara, sensores).
  • Funcionan sin conexión (offline).
Desventajas
  • Altos costos (dos códigos distintos).
  • Tiempo de desarrollo: 4 a 6 meses.
Ejemplos: WhatsAppSpotifyPokémon Go

2. Aplicaciones Web (Web Apps)

Son sitios web optimizados que se ejecutan dentro del navegador móvil. Se desarrollan con HTML5, CSS y JavaScript.

Ventajas
  • Multiplataforma (un solo desarrollo).
  • No ocupan memoria en el dispositivo.
  • Bajo costo y tiempo de desarrollo.
Desventajas
  • Requieren internet siempre.
  • Acceso muy limitado al hardware.
  • Rendimiento depende del navegador.
Ejemplos: Google DocsTrelloNetflix (Web)

3. Aplicaciones Híbridas

Combinan elementos de las dos anteriores. Se programan con tecnologías web pero se "envuelven" en un contenedor nativo para instalarse como una app normal.

Ventajas
  • Única base de código para iOS y Android.
  • Tiempo de desarrollo: ~3 meses.
  • Se pueden subir a la App Store / Play Store.
Desventajas
  • Rendimiento inferior a las nativas.
  • Tamaño de archivo más pesado.
Ejemplos: InstagramUberEvernote
