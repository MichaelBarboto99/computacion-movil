Introducción a Flutter

¿Qué es Flutter?

Es el kit de herramientas de interfaz de usuario de Google para crear aplicaciones compiladas de forma nativa para móvil, web y escritorio desde una única base de código.

Lanzado en 2018, Flutter utiliza el lenguaje de programación Dart. Su principal valor radica en la capacidad de desarrollar para iOS y Android simultáneamente sin comprometer el rendimiento (Pág. 114).

Características de Flutter

Desarrollo Rápido

La función Hot Reload permite ver cambios en el código en menos de un segundo sin perder el estado de la app (Pág. 115).

Rendimiento Nativo

Utiliza el motor gráfico Skia para renderizar su propia UI, asegurando fluidez total en cualquier dispositivo (Pág. 115).

UI Flexible

Arquitectura en capas que permite una personalización total y diseños expresivos mediante un catálogo extenso de widgets.

"Todo es un Widget"

En Flutter, la interfaz se construye ensamblando piezas llamadas widgets, como si fueran bloques de LEGO (Pág. 116). Existen dos tipos fundamentales (Pág. 117):

StatelessWidget

Sin estado: No cambian con el tiempo. Ejemplos: un icono, una etiqueta de texto o un botón simple.

StatefulWidget

Con estado: Son dinámicos y cambian en respuesta a eventos o datos. Ejemplos: Checkbox, Slider o campos de texto.

Componentes de Flutter (Pág. 115)

  • SDK: Colección de herramientas para compilar código para iOS y Android.
  • Framework: Biblioteca de UI basada en widgets reutilizables (botones, entradas, etc.).
