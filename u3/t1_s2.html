TEMA 1 - SUBTEMA 2

Creación de una aplicación de ejemplo

En este ejercicio práctico desarrollaremos una Calculadora básica en Android Studio para comprender el flujo de trabajo real.

1 Configuración Inicial

Iniciamos un nuevo proyecto en Android Studio. Para este caso, seleccionamos la plantilla "Empty Views Activity" (Pág. 96) y nos aseguramos de elegir Java como lenguaje de programación.

2 Estructura Dúplex

Toda interfaz en Android se compone de dos archivos fundamentales que trabajan en conjunto (Pág. 97):


Archivo .XML

Define el diseño visual de la pantalla.


Archivo .JAVA

Define la funcionalidad y lógica.

3 Diseño de la Interfaz

Arrastramos los elementos desde la paleta de herramientas a la interfaz gráfica. Necesitaremos (Pág. 97):

1 TextView: Para mostrar el resultado.
2 EditText: Para ingresar los números.
4 Buttons: Suma, Resta, Mult. y Div.

Tip: Es vital modificar el ID de cada elemento para identificarlo luego en el código.

4 Programación de la Lógica

En el archivo Java, enlazamos los componentes visuales con variables del código usando findViewById y definimos la función de cálculo (Pág. 99-100):

public void sumar(View view) {
  // Lógica para obtener valores y sumarlos...
}

Finalmente, en la parte gráfica del botón, buscamos el evento onClick y seleccionamos la función creada.

5 Prueba en Emulador

Utilizamos el Device Manager para encender el teléfono virtual y ejecutamos la app con el icono de "Play". Si todo es correcto, la calculadora procesará las operaciones en tiempo real (Pág. 100).
