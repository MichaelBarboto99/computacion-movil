Patrón Modelo Vista Controlador (MVC)

En el desarrollo de software, el patrón MVC es una arquitectura que divide las responsabilidades de una aplicación en tres componentes principales para hacerla escalable y fácil de mantener (Pág. 127).

Modelo

Contiene los datos y la lógica de negocio. Encapsula la información.

Vista

Representación de la interfaz de usuario (UI). Muestra los datos.

Controlador

Intermediario. Gestiona la entrada del usuario y actualiza la Vista.

Ventajas de usar MVC (Pág. 129)

Separación de Responsabilidades

Divide claramente datos, UI y lógica, simplificando el mantenimiento del código base.

Reutilización

La estructura modular permite usar componentes en distintas partes de la aplicación.

Escalabilidad

Al desacoplar los componentes, es más fácil añadir nuevas funciones sin afectar al resto del sistema.
