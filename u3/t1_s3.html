Ciclo de Vida, Actividades y Layouts

1. Fases del Ciclo de Vida de una App

Antes de programar, una aplicación atraviesa fases críticas de gestión (Pág. 101):

1. Planificación 2. Desarrollo 3. Test 4. Lanzamiento 5. Monitorización

Monitorización: Es vital analizar el comportamiento del usuario y no solo el número de descargas (Pág. 102).

2. ¿Qué es una Activity?

Es una "pantalla" de la aplicación. Se compone de (Pág. 102):

  • Clase: El código lógico (extiende de AppCompatActivity).
  • Layout: La apariencia visual definida en XML.
  • AndroidManifest: Donde se registra la actividad para que el sistema la reconozca.

Ciclo de Vida de una Activity (Pág. 103)

Métodos que el sistema invoca según el estado de la pantalla:

onCreate(): Primer paso. Se invoca al crear la Activity.
onStart(): La Activity se está iniciando y se hace visible.
onResume(): El usuario ya puede interactuar con la pantalla.
onPause(): Otra actividad se pone en primer plano (parcialmente visible).
onStop(): La Activity ya no es visible para el usuario.
onDestroy(): La Activity se destruye completamente.

El Componente VIEW

Gestiona la interacción del usuario (botones, textos, etc.). Atributos clave (Pág. 104):

layout:heightDimensión vertical (dps).
match_parentAjusta al tamaño del padre.
wrap_contentAjusta al contenido interno.
layout:marginMárgenes externos.
idIdentificador para el código Java.

El Espacio LAYOUT

Contenedor que define la disposición de las Vistas (Pág. 105):

  • LinearLayout: Organiza elementos en fila o columna (muy sencillo).
  • RelativeLayout: Los componentes se organizan de forma relativa entre sí.
  • WebView: Utilizado para mostrar contenido con formato web.
