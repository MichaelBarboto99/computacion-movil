Configuración de entorno Android Studio

Android Studio es el entorno de desarrollo oficial para el sistema operativo Android. Ofrece una gran flexibilidad y herramientas avanzadas para convertir ideas en aplicaciones funcionales.

Características Principales (Pág. 88)

Sistema basado en Gradle (Groovy/Kotlin DSL).
Hot Reload: Modifica código sin reiniciar la app.
Plantillas de compilación y códigos de muestra.
Integración con Google Cloud Platform.

Requisitos Mínimos (Pág. 89)

Windows / macOS / Linux

  • RAM: 8 GB o más.
  • Espacio: 8 GB mínimo (IDE + SDK + Emulador).
  • Resolución: 1280 x 800 mínimo.

Procesador:

Arquitectura x86_64; Intel Core 2da Gen o posterior. En macOS, compatible con chips ARM (Apple Silicon).

El corazón técnico: JDK (Pág. 90)

Antes de instalar el IDE, es fundamental el Java Development Kit (JDK). Este software incluye el intérprete, compilador y herramientas de desarrollo (JDT) necesarias para que las aplicaciones sean portables entre sistemas.

Configuración del Emulador (AVD)

Device Manager

El Android Device Manager se usa para crear y configurar dispositivos virtuales Android (AVD). Esto permite probar la aplicación en diversas configuraciones que simulan teléfonos físicos reales.

Pasos según el compendio (Págs. 94-95):

  1. Seleccionar "Create Device" en el Device Manager.
  2. Elegir la categoría (Phone) y el modelo (ej. Pixel 7).
  3. Seleccionar la imagen del Sistema Operativo (ej. Android 13.0 "Tiramisu").
  4. Verificar la configuración y finalizar.
