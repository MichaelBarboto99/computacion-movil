Trabajar con componentes de Android

Una aplicación Android no es una sola entidad monolítica, sino un conjunto de componentes especializados que interactúan entre sí. Según el compendio (Págs. 106-107), estos son los elementos clave:

Vista (View)

Componente fundamental que engloba los elementos visuales: botones, imágenes, textos y listas. Incluye los Layouts que agrupan estas vistas.

Actividad (Activity)

Representa cada pantalla o ventana. Es el punto de entrada que el usuario ve y con el que interactúa directamente.

Fragmentos (Fragments)

Bloques funcionales que combinan varias vistas. Permiten que la app se ajuste eficientemente a diferentes tamaños de pantalla (Diseño Responsivo).

Intención (Intent)

Representa la voluntad de realizar una acción: abrir una pantalla, realizar una llamada o enviar un mensaje de texto.

Broadcast Receiver

Maneja los avisos del sistema o de otras apps.

Ejemplo: Un aviso del sistema indicando que la batería está baja.

Content Provider

Sistema seguro para compartir datos entre apps, manteniendo la integridad de la información.

Ejemplo: Acceder a la lista de contactos del teléfono.

Servicio (Service)

Es una tarea que se ejecuta de forma oculta para el usuario (background). El compendio los divide en dos tipos:

SERVICIO LOCAL

Se ejecuta en el mismo proceso y dispositivo donde está la aplicación.

SERVICIO REMOTO

Se ejecuta en procesos separados y de forma externa al dispositivo.
